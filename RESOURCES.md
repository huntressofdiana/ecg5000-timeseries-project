# Resources & External Links

Curated tutorials, papers, and tools for self study.

## Python Foundations

| Resource | Description |
|----------|-------------|
| [Official Python Tutorial](https://docs.python.org/3/tutorial/) | Starting point for Python beginners |
| [Real Python](https://realpython.com/) | Practical tutorials on all Python topics |
| [Python Data Science Handbook (VanderPlas)](https://jakevdp.github.io/PythonDataScienceHandbook/) | Free book covering NumPy, pandas, Matplotlib, scikit-learn |

## Deep Learning & PyTorch

| Resource | Description |
|----------|-------------|
| [PyTorch Tutorials](https://pytorch.org/tutorials/) | Official tutorials |
| [Deep Learning with PyTorch (free book)](https://pytorch.org/assets/deep-learning/Deep-Learning-with-PyTorch.pdf) | Introductory book by Stevens, Antiga & Viehmann |

| [Andrej Karpathy: Neural Networks Zero to Hero](https://karpathy.ai/zero-to-hero.html) | Video series building neural nets from scratch |
