# Projects

This folder contains the individual modeling projects for the summer school.

## Overview

Each project is placed in its own sub-folder and has a dedicated `instructions.md` describing the task, dataset, and expected deliverables.

| Folder | Topic | Status |
|--------|-------|--------|
| `project_template/` | Template — copy this to start a new project | — |
| *(to be added)* | | |

## Working on a Project

1. Navigate into the relevant project folder.
2. Read `instructions.md` carefully before starting.
3. Work in your own copy of the folder (or in a personal branch/fork).
4. Submit your results as specified in the project instructions.

## Adding a New Project

Copy the `project_template/` folder, rename it to `project_<name>/`, and fill in the `instructions.md`.
