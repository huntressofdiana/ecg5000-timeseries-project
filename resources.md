# Resources & External Links

A curated collection of tutorials, reference papers, and useful tools for the summer school.
Feel free to suggest additions — open an issue or drop a message in the course channel.

---

## Python Foundations

| Resource | Description |
|----------|-------------|
| [Official Python Tutorial](https://docs.python.org/3/tutorial/) | The canonical starting point for Python beginners |
| [Real Python](https://realpython.com/) | Practical, well-written tutorials on all Python topics |
| [Python Data Science Handbook (VanderPlas)](https://jakevdp.github.io/PythonDataScienceHandbook/) | Free online book covering NumPy, pandas, Matplotlib, and scikit-learn |

## NumPy & Scientific Python

| Resource | Description |
|----------|-------------|
| [NumPy Quickstart](https://numpy.org/doc/stable/user/quickstart.html) | Official NumPy tutorial |
| [Scientific Python Lectures](https://lectures.scientific-python.org/) | Comprehensive lecture notes on the scientific Python stack |

## Deep Learning & PyTorch

| Resource | Description |
|----------|-------------|
| [PyTorch — Getting Started](https://pytorch.org/get-started/locally/) | Official installation guide |
| [PyTorch Tutorials](https://pytorch.org/tutorials/) | Official step-by-step tutorials |
| [Deep Learning with PyTorch (free book)](https://pytorch.org/assets/deep-learning/Deep-Learning-with-PyTorch.pdf) | Introductory book by Eli Stevens, Luca Antiga & Thomas Viehmann |
| [fast.ai Practical Deep Learning](https://course.fast.ai/) | Top-down, code-first introduction to deep learning |
| [Andrej Karpathy — Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) | Video lecture series building neural nets from scratch |

## Time Series & Sequence Modeling

| Resource | Description |
|----------|-------------|
| [The Annotated Transformer (Harvardnlp)](https://nlp.seas.harvard.edu/annotated-transformer/) | Line-by-line walkthrough of the Transformer paper |
| [Illustrated Guide to LSTM & GRU](https://towardsdatascience.com/illustrated-guide-to-lstms-and-gru-s-a-step-by-step-explanation-44e9eb85bf21) | Visual introduction to recurrent architectures |
| [Time Series Forecasting with Deep Learning (Lim & Zohren, 2021)](https://royalsocietypublishing.org/doi/10.1098/rsta.2020.0209) | Survey paper — good overview of the field |
